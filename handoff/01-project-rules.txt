BotControl — ТРЕБОВАНИЯ ПОЛЬЗОВАТЕЛЯ (соблюдать СТРОГО, в каждой итерации)
==========================================================================
Источник: tg-bot-control/ПЕРЕДАЧА-КОНТЕКСТА.md, раздел 7, и прямые указания пользователя в чатах.
Ссылка: https://github.com/visiontripin/oracle/blob/arena/01a0d2d9-oracle/tg-bot-control/ПЕРЕДАЧА-КОНТЕКСТА.md

1. ДИЗАЙН
   • Строгая палитра Telegram:
       background        #0E1621      surface / контейнеры   #17212B
       surfaceVariant    #182533      primaryContainer       #2B5278
       primary           #5288C1      текст                  #F5F6F7
       вторичный текст   #7F91A4      tertiary (акцент)      #FBBF24
       outline           #33475A
   • ТЁМНОГО ТЕКСТА БЫТЬ НЕ ДОЛЖНО: lightTypography() задаёт #F5F6F7 всем стилям.
   • Edge-to-edge: тёмные системные панели и светлые иконки.

2. УПРАВЛЕНИЕ
   • Всё настраивается кнопками, списками и диалогами. Редактор кода нужен
     только для нестандартной JS-логики.
   • В локальном режиме нет экрана логина.
   • Любое удаление — только после подтверждения
     (ui/components/ConfirmDelete.kt: ConfirmRequest + ConfirmHost).
   • «Запустить / Остановить» касается только конкретного бота. «Все боты» —
     это отдельные, явно подписанные кнопки.
   • В интерфейсе нет встроенных пресетов ботов: только подсказки и промт для
     генерации конфига. Шаблоны анимаций (спиннер, прогресс…) — это выбор
     эффекта, а не пресет бота.

3. БЕЗОПАСНОСТЬ
   • Токены лежат в EncryptedSharedPreferences (token_$id) и никогда не
     экспортируются и не коммитятся.
   • Нет публичных эндпоинтов. Файловый сервер включается только вручную и
     работает в локальной сети.
   • Произвольное исполнение запрещено: JS выполняется в Rhino с
     ClassShutter и optimizationLevel -1.
   • В git можно коммитить только debug.keystore (пароль android, alias
     androiddebugkey). Живые токены — никогда.

4. ИИ
   • LLM работает строго на телефоне (LiteRT-LM .litertlm / MediaPipe), без облака.
   • ИИ включается только по необходимости: llmEnabled по умолчанию false.
     ИИ отвечает только на /chat (или /ai) и по правилам с действием «ИИ».
     Все функции бота выполняются КОДОМ (правила, кнопки, наборы, скрипты,
     расписание).

5. МУЛЬТИБОТЫ
   • Настройки строго изолированы по botId.
   • В service/ и data/ ВСЕГДА передавай botId явно: в LocalBotStore -1 =
     «активный в UI бот». Карты в памяти ключуй "$botId:$chatId".
   • Проверка: python3 tg-bot-control/tools/check-bot-isolation.py (шаг CI).

6. БИБЛИОТЕКИ
   • Только проверенные (артефакт реально есть в Maven Central или Google
     Maven). Никаких выдуманных библиотек или API.

7. ДОСТАВКА (каждая итерация)
   • Сначала подними versionCode и versionName в
     tg-bot-control/android/app/build.gradle.kts.
   • Готовый APK из CI (коммит с [apk]), проверка aapt (versionCode/versionName)
     и сертификата (sha256 должен совпадать с
     2ecc9b73dd43d0b40cd032c3e83d2e7f4a549680d513a10b7ed5510e51e20d5e).
   • Понятная сводка на русском.
   • ВСЕ файлы, которые пользователю нужно скачать, даются ПРЯМЫМИ ССЫЛКАМИ:
       https://github.com/visiontripin/oracle/releases/download/<тег>/<файл>
     Тег имеет вид botcontrol-v<versionName>-code<versionCode>. К релизу
     автоматически прикладываются APK, все tg-bot-control/*-ready.py,
     branding/avatar-640.png и handoff/*.txt.
   • Обнови RELEASE-NOTES.md (новая версия сверху), раздел 2 и 9 в
     ПЕРЕДАЧА-КОНТЕКСТА.md и строку «Текущая доставка» в корневом README.md.

8. GIT
   • Git — единственный источник истины. Всё, что должно пережить чат,
     коммитится и пушится: исходники, конфиги, доки, воркфлоу, tools/.
   • Работай в ветке своей сессии. В main не вливай сам — это делает
     пользователь через PR.

9. ПОВЕДЕНИЕ ИМПОРТИРОВАННОГО БОТА
   • Импортированный из python бот обязан вести себя как оригинал (оракл
     «Агент Смит / перекур»: расписание будни + пятница, /start с кнопками
     Запуск/Стоп, перекурные кнопки, SYSTEM_PROMPT, cooldown 10 с, typing 4 с,
     память 4 реплики).
   • Грамматика импорта: раздел 5 ПЕРЕДАЧА-КОНТЕКСТА.md и
     tg-bot-control/Инструкция-код-бота.md.
     Промт генерации конфигов: tg-bot-control/Промт-создание-ботов.md.
