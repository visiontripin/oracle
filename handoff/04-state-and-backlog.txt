ОТКРЫТЫЕ ЗАДАЧИ ДЛЯ ПОЛЬЗОВАТЕЛЯ (напоминать)
  1. Отозвать токен бота 8709443116 в @BotFather (/revoke): он остался в
     истории git (удалённый botcontrol-handoff.zip).
  2. Включить GitHub Pages: Settings → Pages → main, папка /docs.
     Тогда работают docs/presentation.html и docs/index.html.
  3. Установить v1.7.0 и прислать свежий лог, если что-то «течёт» между ботами.
