# Промт: генерация логики новых ботов для BotControl (v2, с резервированием имён)

Этот промт учит любую нейросеть (ChatGPT, Claude, Gemini — или мне в чате)
сразу выдавать код в формате, который приложение импортирует без ошибок.
В v2 добавлен полный реестр зарезервированных имён — их использование под
другие цели ломает импорт или меняет поведение приложения.

**Как пользоваться:** скопируй блок из раздела «Промт», замени текст в
`[квадратных скобках]` и отправь ИИ. Полученный код проверь в приложении:
Скрипты → Импорт настроек из кода → вставить → **Разобрать** (все категории
на месте?) → **Применить к боту** → ▶ Запустить → /start в Telegram.

---

## Промт (копируй отсюда)

```text
Ты — генератор конфигураций для приложения BotControl (Android, локальные
Telegram-боты). Выведи ОДИН блок кода на Python. Это не исполняемый скрипт,
а конфиг: приложение читает его текст и раскладывает по категориям настроек.
Никаких пояснений вне блока кода, никаких import, никаких вызовов API.

ЖЁСТКИЕ ПРАВИЛА СИНТАКСИСА (нарушение = категория не импортируется):
1. Один элемент списка — одна строка вида:    "текст",
   Закрывающая скобка ] — ВСЕГДА на отдельной строке.
2. SYSTEM_PROMPT = ( ... ) — многострочная склейка обычных строк в кавычках;
   перенос строки внутри текста обозначай \n.
3. Текст ответа команды — обычные строки в кавычках внутри bot.send_message(...).
   Подстановки: {name} — имя пользователя, {text} — его сообщение,
   {bot} — ник бота. Длина текста команды — до 2000 символов.
4. Расписание — ТОЛЬКО внутри def get_today_schedule(now): кортежи
   (ЧАС, МИНУТЫ, "текст"), часы 0–23, минуты 0–59. Зоны дней недели:
   - кортежи ДО строки `if wd < 5:` → каждый день (Пн–Вс);
   - внутри `if wd < 5:` → будни Пн–Пт;
   - внутри `if wd == 4:` → только пятница;
   - внутри `else:` → Пн–Чт.
   Слово ПЕРЕКУР в тексте события автоматически добавляет кнопки
   «🚬 Покурил / 💪 Остался здоровым / 😂 Рандомную шутку» — пиши его
   только если это действительно перекур.
5. Кнопки «Запуск/Стоп» (включение напоминаний) не описывай текстом:
   они появляются сами, если в коде есть InlineKeyboardButton с надписями
   «▶️ Запуск» и «⏹ Стоп» и callback_data.

РЕЕСТР ЗАРЕЗЕРВИРОВАННЫХ ИМЁН (использовать ТОЛЬКО по назначению;
для наборов ответов и переменных эти имена запрещены — конфликтуют
со встроенной логикой приложения):

  Системные константы (только штатное значение):
    BOT_TOKEN, SYSTEM_PROMPT, LLM_MAX_TOKENS, LLM_MAX_TOP_K,
    MAX_HISTORY, HISTORY_LIMIT, ANSWER_COOLDOWN, COOLDOWN,
    TYPING_SECONDS, DEFAULT_TYPING_SECONDS

  Служебные имена списков (приложение считает их настройками,
  НЕ наборами ответов — наборы с такими именами будут выброшены):
    schedule, commands, content_types, messages, history, days,
    buttons, menu, items, payload, choices, keyboards

  Зарезервированные наборы (можно переопределять содержимое,
  но имя = встроенное поведение):
    JOKES            — «😂 Шутки» (кнопка «😂 Рандомную шутку»)
    SMOKE_DONE_SARCASM    — реакция кнопки «🚬 Покурил»
    SMOKE_HEALTHY_SARCASM — реакция кнопки «💪 Остался здоровым»
    CLARIFY_QUESTIONS     — уточняющие вопросы, когда ИИ недоступен
    SMOKE_DONE, SMOKE_HEALTHY, CLARIFY — то же самое, алиасы

  Зарезервированные функции:
    get_today_schedule(now) — расписание напоминаний
    cmd_<имя> (cmd_start, cmd_help, cmd_rules, …) — обработчики команд:
      имя из cmd_<имя> становится командой /<имя>, поэтому пиши
      латиницей: cmd_start, а не cmd_старт
    keyboard(), smoke_keyboard() — встроенные клавиатуры:
      названия надписей «▶️ Запуск», «⏹ Стоп», «🚬 Покурил»,
      «💪 Остался здоровым», «😂 Рандомную шутку» зарезервированы —
      эти кнопки получают встроенные действия

  Свои наборы ответов называй иначе, например:
    MORNING_PHRASES, BEDTIME_LINES, FAQ_ANSWERS, WELCOME_BACK_LINES

ЧИСЛОВЫЕ ПАРАМЕТРЫ — строго этими именами:
    LLM_MAX_TOKENS = число
    MAX_HISTORY = число            # память диалога, реплик
    ANSWER_COOLDOWN = число        # пауза между ответами, сек
    DEFAULT_TYPING_SECONDS = число # «печатает…», сек
    payload = {
        "temperature": 0.7,
        "max_tokens": LLM_MAX_TOKENS,
    }

ЗАПРЕЩЕНО: f-строки с выражениями, вложенные списки, словари в списках,
вызовы requests/asyncio/os/sqlite, импорты, регулярки, HTML-разметка.
Приложение читает только строковые литералы и числа.

СТРУКТУРА ВЫВОДА (соблюдай порядок):
# комментарий-название бота
BOT_TOKEN = "ТОКЕН_НЕ_ИМПОРТИРУЕТСЯ"
SYSTEM_PROMPT = ( ... )
LLM_MAX_TOKENS = ...
MAX_HISTORY = ...
ANSWER_COOLDOWN = ...
DEFAULT_TYPING_SECONDS = ...
payload = { "temperature": ..., "max_tokens": LLM_MAX_TOKENS }
@bot.message_handler(commands=["start"]) / def cmd_start ...
@bot.message_handler(commands=["help"]) / def cmd_help ...
ИМЯ_НАБОРА_1 = [ ... ]
CLARIFY_QUESTIONS = [ ... ]
def get_today_schedule(now): ...

ЗАДАНИЕ: создай бота: [РОЛЬ — кто бот и с каким характером;
ЧТО ДЕЛАЕТ — отвечает/развлекает/напоминает/собирает данные;
КОМАНДЫ — кроме /start и /help, если нужны;
НАБОРЫ — какие готовые списки ответов (имена придумаешь из реестра
свободных имён, ЗАГЛАВНЫМИ, латиницей, через подчёркивание);
РАСПИСАНИЕ — какие напоминания и в какие дни;
ОСОБЕННОСТИ — тон, длина ответов, что запрещено]
```

## Пример заполненного ЗАДАНИЯ

```text
ЗАДАНИЕ: создай бота: роль — «Бариста-бот» кофейни, тон дружелюбный,
отвечает коротко; принимает заказ словами (эспрессо, капучино, раф);
наборы: CROISSANT_JOKES — 15 шуток про круассаны, THANK_YOU_LINES —
10 фраз благодарности за заказ; расписание: ежедневно в 8:00 «☕ Мы
открылись!», в будни в 15:00 «🍰 Десерт −20% после обеда», в пятницу
в 18:00 «🎉 Пятничный латте по цене эспрессо»; уточняющие вопросы:
«Какой кофе?», «С собой или здесь?», «Сколько сахара?»; запрет: не
обсуждать темы, не связанные с кофе.
```

## Если категория не появилась при «Разобрать»

| Симптом | Причина |
|---|---|
| Нет «Характер ИИ» | SYSTEM_PROMPT не в склейке строк `( "…" "…" )` |
| Нет набора | элемент не на своей строке, `]` не на отдельной строке, или имя из служебного реестра |
| Нет событий расписания | кортежи вне get_today_schedule или часы вне 0–23 |
| Приветствие пустое | текст не в кавычках внутри bot.send_message( |
| Кнопки перекуров не там | слово «ПЕРЕКУР» попало в обычное событие |
| Команда не появилась | def cmd_старт (кириллица) — только латиница |
| Текст обрезался | длиннее 2000 символов — сократи |

Грамматика проверена на импортёре v1.4.9 (ScriptImporter).
