# Инструкция: код настроек бота для BotControl (написание / правка / импорт)

Файл **bot-config-ready.py** — рабочий конфиг бота («Агент Смит», перекуры,
расписание будни+пятница), переписанный под импортёр приложения. Он
импортируется полностью и без замечаний: характер ИИ, память, паузы, команды,
приветствие с кнопками, /help, 100 шуток, сарказм, уточняющие вопросы и
расписание со всеми зонами (ежедневное / будни / Пн–Чт / пятница).

Ещё один рабочий пример — **demo-конфиг из раздела 5** (кнопки-ссылки,
клавиатура чата, обработчик нажатий, условия `wd in (5, 6)`).

---

## 1. Как импортировать (в приложении)

1. Открой файл конфига, скопируй весь текст (или перекинь файл на телефон).
2. Приложение → тапни по боту → **Скрипты → Импорт настроек из кода**.
3. Вставь текст в поле **или** нажми «📂 Выбрать файл» (.py / .js / .txt).
4. Нажми **🔍 Разобрать** — приложение покажет найденное по категориям
   (ИИ, поведение, команды, правила, клавиатура, наборы, расписание, канал)
   и раздел **«Замечания»** — что понять не удалось.
5. Галочками отметь нужные категории → **✅ Применить к боту**.

### Обязательно после импорта (иначе «ничего не приходит»)

1. Карточка бота → **▶ Этот бот** (в статусе не должно быть ⚠️-проблем).
2. В Telegram отправь боту **/start** — придёт приветствие с кнопками.
3. Нажми **▶️ Запуск** под сообщением — бот подтвердит включение напоминаний.
4. Напоминания идут в последний чат, откуда писали боту.

## 2. Что распознаётся в коде (грамматика импорта v1.5.2)

| Блок в коде | Куда попадает в приложении |
|---|---|
| `SYSTEM_PROMPT = ( "…" "…" )` | ИИ → Характер |
| `LLM_MAX_TOKENS`, `LLM_MAX_TOP_K`, `"temperature"` в `payload` | ИИ → параметры генерации |
| `MAX_HISTORY` / `HISTORY_LIMIT` | Поведение → Память диалога (реплик) |
| `ANSWER_COOLDOWN` | Поведение → Пауза между ответами |
| `DEFAULT_TYPING_SECONDS` | Поведение → «Печатает…» |
| `@bot.message_handler(commands=["start"]) def cmd_start` | Правило «Команда /start» |
| `@bot.message_handler(func=lambda m: m.text == "…")` | Правило «Кнопка» (точное совпадение) |
| `@bot.message_handler(func=lambda m: "фраза" in m.text.lower())` | Правило «Содержит» |
| `reply_markup=имя_меню()` в send_message | Inline-кнопки под ответом правила |
| `def имя_меню(): … InlineKeyboardMarkup() … .row(InlineKeyboardButton(...))` | Меню (ряды сохраняются) |
| `InlineKeyboardButton("…", url="…")` | Кнопка-ссылка (не шлёт боту ничего) |
| `@bot.callback_query_handler` + ветки `call.data == "…"` | Действие кнопки + всплывашка |
| `answer_callback_query(call.id, "текст")` | Всплывашка при нажатии |
| `send_message(...)` в обработчике | Кнопка присылает новое сообщение |
| `edit_message_text(...)` в обработчике | Кнопка правит сообщение под собой |
| `bot_running = True / False` (переменная напоминаний) | Кнопка вкл/выкл напоминания |
| `def chat_keyboard(): ReplyKeyboardMarkup(... KeyboardButton("…"))` | Клавиатура чата (прикрепи `reply_markup=chat_keyboard()`) |
| `ИМЯ_НАБОРА = [ "…", ]` | 🎲 Набор ответов (имя — из названия константы) |
| `random.choice(ИМЯ)` | Действие «случайное из набора» (правило или кнопка) |
| `CLARIFY_QUESTIONS = [ … ]` | Поведение → Уточняющие вопросы |
| `(ЧАС, МИН, "текст")` в `get_today_schedule` | ⏰ Событие расписания |
| `(ЧАС, МИН, "текст", имя_меню())` | Событие с inline-кнопками под напоминанием |
| `»канал` в начале текста события | Публиковать в канал, а не в чат |
| варианты через `" | "` | Ротация текста по дням года |
| `CHANNEL_ID = "@канал"`, `LISTINGS_MODE = True` | Настройки бота: канал и объявления |
| `bot.set_my_commands([...])` | Меню Telegram (кнопка «Меню») |

### Зоны дней недели (в `get_today_schedule`)

- Кортежи **до** `if wd < 5:` → каждый день (Пн–Вс).
- Внутри `if wd < 5:` → **будни (Пн–Пт)**.
- Внутри `if wd == 4:` → **только пятница**.
- Внутри `else:` после пятничной ветки → **Пн–Чт**.
- Поддерживаются и другие условия: `now.isoweekday()`, `if wd in (5, 6):`,
  `if 0 <= wd <= 4:`, вложенные `if`/`elif`/`else` любой глубины.

Работает старая конвенция «слово ПЕРЕКУР → кнопки 🚬/💪/😂», но она
включается только если в коде есть условие вида
`reply_markup = smoke_keyboard() if is_smoke_event(text) else None`.
Надёжнее указывать меню явно — 4-м элементом кортежа:
`(15, 55, "🔥 ПЕРЕКУР", smoke_keyboard()),`.

## 3. Как править и дополнять код

**Формат строк (важно для распознавания):**

- один элемент списка — одна строка: `"текст",`;
- закрывающая `]` — **на отдельной строке**;
- комментарии `# …` можно оставлять где угодно;
- внутри `"…"` кавычку пиши как `\"`, перенос строки как `\n`;
- строка после `ИМЯ_НАБОРА = [` становится названием набора:
  `MORNING_PHRASES = [  # Утренние фразы` → набор «Утренние фразы».

**Добавить команду:**
```python
@bot.message_handler(commands=["ping"])
def cmd_ping(msg):
    bot.send_message(msg.chat.id, "Понг. Система стабильна.")
```
→ появится и в меню Telegram, и как правило с этим текстом.

**Добавить кнопку под сообщением + её действие:**
```python
def menu_keyboard():
    markup = InlineKeyboardMarkup()
    markup.row(InlineKeyboardButton("🎲 Шутка", callback_data="joke"))
    return markup

@bot.callback_query_handler(func=lambda call: True)
def on_callback(call):
    if call.data == "joke":
        bot.answer_callback_query(call.id, "Лови")
        bot.send_message(call.message.chat.id, random.choice(JOKES))
```
и прикрепи меню к ответу: `bot.send_message(msg.chat.id, "…", reply_markup=menu_keyboard())`.

**Добавить событие расписания** — кортеж в нужной зоне (см. таблицу зон выше).

**Изменить характер** — правь строки `SYSTEM_PROMPT`.

Всё это правится и кнопками в приложении (Правила / Кнопки / Наборы /
Поведение / Напоминания), а **Скрипты → Экспорт настроек в код** выгрузит
твой вариант обратно в этот же формат — вместе с меню и рядами кнопок.

## 4. Что было сломано раньше — и как теперь

| Было | Стало (v1.5.2) |
|---|---|
| Кнопки из кода не импортировались (только надписи) | Разбираются меню **и** обработчики: действие, всплывашка, набор, правка сообщения, вкл/выкл напоминаний |
| Ряды кнопок задать было нельзя | `markup.row(...)` → ряд 1, 2, 3…; в редакторе кнопки есть поле «Ряд кнопок» |
| Кнопки-ссылки только внутри «Объявлений» | Любая кнопка может быть `url=…` (действие «Открыть ссылку») |
| Клавиатура чата из кода игнорировалась | `ReplyKeyboardMarkup` + `KeyboardButton` импортируются |
| Ответы на кнопки клавиатуры/фразы не переносились | `func=lambda m: m.text == "…"` и `in m.text.lower()` → правила «Кнопка» и «Содержит» |
| Условия дней недели только `wd < 5` / `wd == 4` | Любые `if/elif/else` по `wd`, `weekday()`, `isoweekday()`, диапазоны и `in (…)` |
| Меню под напоминанием — только по слову ПЕРЕКУР | 4-й элемент кортежа `(h, m, "текст", меню())` |
| Приложение молча «теряло» непонятное | Раздел «Замечания» честно перечисляет, что поправить |
| Кнопка одного бота срабатывала у другого | Поиск кнопки только среди меню этого бота |

## 5. Если что-то ведёт себя не так — чек-лист

- **Не приходят напоминания** → бот запущен? Напоминания включены (▶️ Запуск)?
  В этот чат уже писали боту? Смотри «Журнал событий» в дереве бота.
- **Кнопка «устарела»** → после правок меню в приложении нажми /start заново:
  у старых сообщений осталась прежняя разметка.
- **Кнопка ничего не делает** → «Сценарии → Кнопки бота»: у кнопки должно быть
  действие (не пустой текст) и правило-обработчик для кнопок клавиатуры.
- **В импорте пусто** → проверь, что файл в кодировке UTF-8, а блоки записаны
  по структуре из раздела 2 (особенно `]` на отдельной строке).
- **«Набор пуст»** → набор с таким именем есть, но в нём нет фраз:
  открой «🎲 Наборы ответов» и добавь элементы.
- **Конфликт 409** → токен опрашивается ещё где-то (Termux, второй поллер) —
  останови второй экземпляр.
