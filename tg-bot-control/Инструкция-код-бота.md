# Инструкция: код настроек бота для BotControl (написание / правка / импорт)

Файл **bot-config-ready.py** — готовый рабочий код твоего бота («Агент Смит», перекуры,
расписание будни+пятница), переписанный специально под импортёр приложения.
Он импортируется без ошибок и полностью: характер ИИ, память, паузы, команды,
приветствие с кнопками, /help, все 100 шуток, сарказм, уточняющие вопросы и
расписание со всеми зонами (ежедневное / будни / Пн–Чт / пятница).

---

## 1. Как импортировать (в приложении)

1. Открой файл `bot-config-ready.py`, скопируй весь текст (или скачай и перекинь на телефон).
2. Приложение → твой бот → **📜 Скрипты → Импорт настроек из кода**.
3. Вставь текст в поле **или** нажми «Выбрать файл» (подходит .py / .js / .txt).
4. Нажми **Разобрать** — приложение покажет список найденных категорий
   (характер ИИ, температура, «печатает…», команды, приветствие, наборы, события…).
5. Галочками отметь, что применить (по умолчанию всё), → **✅ Применить к боту**.

### Обязательно после импорта (иначе «ничего не приходит»):
1. Карточка бота → **▶ Запустить** (в статусе не должно быть ⚠️-проблем).
2. В Telegram отправь боту **/start** — придёт приветствие с кнопками ▶️ Запуск / ⏹ Стоп.
3. Нажми **▶️ Запуск** под сообщением — бот ответит «Напоминания включены» с полным расписанием.
4. Напоминания приходят в тот чат, откуда было последнее сообщение (так же, как в python-оригинале).

## 2. Что распознаётся в коде (грамматика)

| Блок в коде | Куда попадает в приложении |
|---|---|
| `SYSTEM_PROMPT = ( "…" "…" )` | ИИ → Характер (многострочно, склейка строк) |
| `"temperature": 0.7` в `payload` | ИИ → Температура |
| `LLM_MAX_TOKENS = 80` | ИИ → Максимум токенов |
| `MAX_HISTORY = 4` | Поведение → Память диалога (реплик) |
| `ANSWER_COOLDOWN = 10` | Поведение → Пауза между ответами (антифлуд) |
| `DEFAULT_TYPING_SECONDS = 4` | Поведение → «Печатает…» секунды |
| `@bot.message_handler(commands=["start","help"])` | Меню Telegram (setMyCommands) |
| `def cmd_start` + `send_message(…, "ТЕКСТ", reply_markup=…)` | Правило команды /start + приветствие; `{name}` = имя пользователя |
| `def cmd_help` (и любой `def cmd_xxx`) | Правило команды /help (текст из send_message) |
| `InlineKeyboardButton("▶️ Запуск", callback_data=…)` + «Стоп» | Кнопки Запуск/Стоп у приветствия (включение напоминаний) |
| `JOKES = [ "…" ]` (большие списки строк) | 🎲 Наборы ответов — «😂 Шутки» |
| `SMOKE_DONE_SARCASM = [ … ]` | Набор «🚬 Сарказм: покурил» (его отдаёт кнопка 🚬) |
| `SMOKE_HEALTHY_SARCASM = [ … ]` | Набор «💪 Сарказм: остался здоровым» |
| `CLARIFY_QUESTIONS = [ … ]` | Поведение → Уточняющие вопросы (fallback без ИИ) |
| `(ЧАС, МИНУТЫ, "текст")` внутри `get_today_schedule` | ⏰ Напоминания: расписание с днями недели |

### Зоны расписания (как в python-оригинале)
- Кортежи **до** `if wd < 5:` → каждый день (Пн–Вс).
- Внутри `if wd < 5:` до ветки с `wd == 4` → **будни (Пн–Пт)**.
- Внутри `if wd == 4:` → **только пятница**.
- Внутри `else:` после пятничной ветки → **Пн–Чт**.
- Событие с текстом, где есть «ПЕРЕКУР», автоматически получает кнопки
  🚬 Покурил / 💪 Остался здоровым / 😂 Рандомную шутку.

Имена наборов важны: `JOKES`, `SMOKE_DONE_SARCASM`, `SMOKE_HEALTHY_SARCASM`,
`CLARIFY_QUESTIONS` — узнаваемые, попадают в правильные наборы и связываются
с кнопками. Свои новые наборы называй латиницей БОЛЬШИМИ_БУКВАМИ.

## 3. Как править и дополнять код

**Формат строк (важно для распознавания):**
- один элемент списка — одна строка: `"текст",`;
- закрывающая `]` — **на отдельной строке**;
- комментарии `# …` можно оставлять где угодно;
- в тексте внутри `"…"` кавычку пиши как `\"`, перенос строки как `\n`.

**Добавить команду** (например /ping):
```
@bot.message_handler(commands=["ping"])
def cmd_ping(msg):
    bot.send_message(msg.chat.id, "Понг. Система стабильна.", )
```
→ появится и в меню Telegram, и как правило с этим текстом.

**Добавить набор ответов:**
```
MORNING_PHRASES = [
    "Доброе утро, мистер Андерсон.",
    "Система проснулась первой.",
]
```

**Добавить событие расписания** — кортеж в нужную зону:
`(7, 30, "☀️ Подъём, мистер Андерсон"),` — до `if wd < 5:` = каждый день;
внутри будней = Пн–Пт; в `else:` = Пн–Чт; в `if wd == 4:` = только пятница.

**Изменить характер** — правь строки `SYSTEM_PROMPT` (каждая строка в кавычках,
переносы как `\n`).

Ничего из этого можно не делать руками: после импорта всё то же самое
редактируется кнопками в самом приложении (Правила / Наборы / Поведение /
Напоминания), а **Скрипты → Экспорт настроек в код** выгрузит твой вариант
обратно в этот формат.

## 4. Что было сломано раньше (причины «те же ошибки») — исправлено в v1.4.6

1. **Шутки не импортировались вообще.** Парсер от `commands=["start"]` захватывал
   чужой список — первым `\n]` оказывалось закрытие JOKES. Теперь список — это
   только строковые литералы, код не «съедается».
2. **Кнопки 🚬/💪/😂 отвечали «Набор пуст».** Импортированные наборы получали id
   `imp_…`, а кнопки ссылаются на стабильные `pack_jokes / pack_smoke_done /
   pack_smoke_healthy`. Теперь известные наборы сразу сохраняются под этими id.
3. **Не было событий Пн–Чт 15:55 и 16:55** — ветка `else:` после пятничной не
   распознавалась. Теперь `else:` = «все дни, кроме пятницы».
4. **Пятница 15:55 затирала будничное 15:55** (дедупликация по времени без учёта
   дней) — теперь дедупликация учитывает дни недели.
5. **Напоминания оставались выключенными** после импорта — теперь включаются
   автоматически (но кнопкой ▶️ Запуск в Telegram их всё равно можно стоповать/возобновлять).
6. **Текст /help не переносился** — теперь тексты всех `def cmd_xxx` становятся правилами.

## 5. Если что-то ведёт себя не так — быстрый чек-лист

- **Не приходят напоминания** → бот запущен? ▶️ Запуск нажат? В этот чат уже
  писали боту? (бот шлёт в чат последнего сообщения). Смотри 📜 Журнал событий
  в главном меню бота — там видно каждое срабатывание и ошибки.
- **⚠️ Меню Telegram: HTTP 400** → команда с некорректным именем/описанием;
  приложение само чистит имена и подставляет описание — проблема исчезнет из
  карточки, когда Telegram примет меню.
- **⚠️ Конфликт 409** → токен этого бота где-то ещё опрашивается (старый Termux,
  другой poller) — останови второй источник.
- **Отвечает «Набор пуст»** → обнови APK до v1.4.6+ и переимпортируй файл.
- **ИИ молчит / уточняет** → модель не загружена (вкладка ИИ на устройстве) —
  fallback тогда задаёт уточняющие вопросы, это штатное поведение оригинала.
