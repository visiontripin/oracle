# BotControl v1.5.3 (code 23)

## ИИ — только по необходимости (главное изменение)
- Функции бота выполняются **кодом**: правила, кнопки, наборы, скрипты JS, расписание — без ИИ.
- ИИ больше **не отвечает «на всё»**: по умолчанию выключен; даже включённый отвечает только в
  отдельных сценариях — команда `/chat вопрос` (или `/ai вопрос`) и правила с действием «ИИ».
- Переключатель «Включить ИИ» — на главном экране бота (с названием модели) и в «Правила ответов».
- Без настроенного ИИ бот отвечает кодовым запасным ответом (уточняющий вопрос / свой текст),
  а на `/chat` — подсказкой, что включить.

## Кнопки: исправления и самоисцеление импорта
- Кнопки-ссылки (`url=`) больше не присылают пустое сообщение «…» — Telegram сам открывает ссылку.
- Импорт теперь **обновляет существующие правила по паттерну** (не по типу): повторный импорт
  чинит правила, сохранённые старой версией, и убирает дубли. В сводке видно:
  «правил: N (обновлено X, убрано дублей Y), кнопок: Z».
- Ненайденная кнопка: всплывашка «Кнопка устарела: пересыль /start…», а список известных кнопок
  попадает в «Журнал событий» (диагностика).
- **Установите этот APK и заново пройдите «Импорт → Разобрать → Применить к боту»** —
  так гарантированно обновятся сохранённые кнопки.

## Встроенные примеры убраны
- Из «Меню» удалена кнопка «Пример» (start/help/joke) — остался «+ Команда меню» и подсказка.
- Из «Имитации» удалён чип «перекур» — вместо него «🤖 /chat».
- Примеров ботов нет: только подсказки, промт и импорт кода.

## Сброс и промт
- «⚠️ Сбросить настройки бота» — теперь на **главном экране бота** (в карточке, рядом с кнопками
  запуска/удаления), с подтверждением.
- Промт для создания бота (v4): короче и жёстче; закреплено, что все функции — кодом, ИИ —
  отдельный сценарий; у каждой кнопки свой callback_data и своя ветка обработчика.
