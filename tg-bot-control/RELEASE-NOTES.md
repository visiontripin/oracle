# BotControl v1.5.5 (code 25)

## Починены кнопки визарда объявлений (главное)

Симптом: «📝 Разместить объявление» запускал визард, но на шаге 2 кнопки
«✉️ Написать в личку» / «📞 Указать телефон» не работали, а в журнале было
`⚠️ Кнопка 'cb-1230402332' не найдена в меню этого бота`.

Причина (регресс с v1.5.2): у служебных кнопок визарда есть только код
действия `lst_…`, а в Telegram вместо него отправлялся хеш надписи
(`cb-1230402332` — это ровно «✉️ Написать в личку»). Бот не узнавал свои
же кнопки. Сломаны были все 14 inline-кнопок визарда: контакт, «Готово,
к публикации», «Без фото», «Опубликовать», «Отменить», «Переопубликовать»,
«Удалить».

- Кнопки визарда отправляются со своими кодами `lst_…` — весь путь
  описание → контакт → фото → предпросмотр → публикация проходит кнопками.
- **Уже отправленные сообщения тоже работают**: кнопки из старых
  сообщений (с `cb<хеш>`) распознаются по надписи.
- Сообщения и нажатия в режиме «Объявления» теперь видны в «Журнале
  событий» (раньше визард работал «молча»).

## Импорт

- Убрано ложное «без действия: 3» для кнопок визарда: режим «Объявления»
  из того же импорта учитывается сразу.

## После установки

1. Обновите APK поверх старого (повторный импорт не нужен).
2. Перезапустите бота, отправьте /start → «📝 Разместить объявление» →
   описание → «✉️ Написать в личку» → фото или «⏭ Без фото» →
   «✅ Опубликовать».
3. Бот должен быть администратором канала @daromvpl с правом публикации.
