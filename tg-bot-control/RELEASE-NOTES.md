# BotControl v1.5.6 (code 26)

## Переопубликация без дублей в канале

Симптом: после «📋 Мои объявления → 🔄 Переопубликовать» в канале стало
2 поста, а «🗑 Удалить» убрало только один.

Причина: при переопубликации бот выкладывал новый пост и **заменял** список
сообщений объявления на новый — старый пост оставался в канале, и бот
про него забывал. Удаление видело только последний пост.

- «🔄 Переопубликовать» теперь **поднимает** объявление: новый пост
  публикуется, после успеха старый удаляется — в канале всегда одно
  объявление. В журнале: «♻️ Переопубликация …: убрано старых сообщ. N из N».
- Если старый пост удалить не удалось (у бота нет права «Удалять сообщения»
  или пост старше 48 ч), бот его **не забывает** — «🗑 Удалить» попробует снова.
- «🗑 Удалить» честно сообщает результат: при неудаче — сколько удалено,
  сколько нет и причина от Telegram; объявление остаётся в списке для повтора.
- Посты **без фото** тоже запоминаются (раньше их id не сохранялся и удалить
  такой пост из бота было нельзя).

## После установки

1. Обновите APK поверх старого (импорт повторять не нужно).
2. Пост, который остался в канале от прошлой переопубликации, бот уже
   «забыл» — удалите его вручную в канале один раз.
3. Убедитесь, что у бота в @daromvpl есть право «Удалять сообщения».
