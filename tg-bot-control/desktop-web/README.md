# Локальный веб-редактор BotControl (первый этап)

Требуется Python 3.9 или новее. Windows: `py server.py`; Linux: `python3 server.py` (в этой папке). Откроется браузер по адресу http://127.0.0.1:8765/. Остановить сервер: Ctrl+C. Другой порт: `python3 server.py --port 8766`. Сервер слушает только локальный интерфейс и не выполняет импортированные файлы.

Создайте сценарии и привяжите их к кнопкам. Изменения хранятся в локальном хранилище конкретного браузера и могут исчезнуть при очистке его данных. Экспортируйте `.bc` для резервной копии и переноса. Импорт `.bc` заменяет текущего бота после подтверждения; файл представляет собой JSON версии 1. Токены в редакторе не используются.

Импорт ответов: текстовый файл UTF-8, каждый ответ начинается с номера и точки (или скобки), например:

```text
1. Первый ответ
2. Второй ответ
   продолжение второго ответа
```

Ответы добавляются как сценарии, существующие данные не заменяются. При необходимости можно изменить их названия и привязать к кнопкам.

## Запуск бота

Создайте непустой сценарий и задайте ему команду или фразу, либо добавьте кнопку с уникальным названием и привяжите её к сценарию. Вставьте токен от @BotFather и нажмите «Запустить бота». Откройте бота в Telegram и отправьте `/start`: появится клавиатура, кнопки будут отправлять привязанные ответы. Для работы нужны интернет и запущенный `server.py`; браузер можно закрыть. После редактирования остановите и заново запустите бота. Один токен нельзя одновременно использовать для polling на другом устройстве. Токен не сохраняется и не экспортируется; после перезапуска его нужно ввести заново.

**Ограничения:** реализованы текстовые ответы, текстовые анимации и клавиатура с кнопками, не все функции Android. Формат `.bc` пока не совместим с Android-приложением; импорт и экспорт `.py` не реализованы. Данные редактора хранятся в браузере, а не в процессе бота. Это локальное приложение, а не публичный веб-сервис. Не предоставляйте доступ к нему другим пользователям. При завершении `server.py` бот останавливается.

## Windows: запуск и сборка

Готовая Windows-сборка создаётся заданием **BotControl Windows** в GitHub Actions. После успешного запуска скачайте артефакт `BotControl-Windows`, распакуйте архив и запустите `BotControl.exe`. Установка Python для этого не нужна. Программа открывает браузер и оставляет консольное окно открытым: пока окно работает, бот может отвечать. Закрытие окна останавливает бота. При повторном запуске введите токен заново. Не распространяйте непроверенные исполняемые файлы; эта сборка не подписана и Windows может предупредить об этом.

Для запуска из исходников с установленным Python 3.9+ можно дважды нажать `Start-BotControl.cmd`. При занятом порте 8765 закройте уже работающий экземпляр; не выбирайте произвольный порт как постоянный обходной путь: хранилище браузера привязано к адресу и порту. При использовании другого браузера или порта импортируйте резервную копию `.bc`.

Сборка на Windows вручную (Python 3.11, из этой папки):

```powershell
py -3.11 -m pip install pyinstaller==6.11.1
py -3.11 -m PyInstaller --noconfirm --clean --onefile --name BotControl --add-data "index.html;." --add-data "style.css;." --add-data "app.js;." server.py
```

Результат — `dist\BotControl.exe`. Это не установщик и не отдельный нативный интерфейс: управление происходит в браузере на локальном компьютере.

## Android / Termux

Для экспериментального запуска в Termux и управления из браузера в доверенной домашней Wi‑Fi сети см. [подробную инструкцию](TERMUX.md). Публичный доступ не реализован; LAN-режим не имеет авторизации и HTTPS.

Предварительная сборка для Windows публикуется как отдельный prerelease; кроме тестов приложения CI запускает собранный `.exe` и проверяет выдачу страницы и статуса. Интеграция с реальным Telegram в CI не проверяется.


## Анимации

Создайте сценарий, выберите действие «Анимация» и один из 10 текстовых шаблонов Android: спиннер, прогресс, точки, отсчёт, печатная машинка, матрица, слоты, луна, часы или сердце. Также можно создать свои кадры, разделяя их строкой `---`. Укажите подпись, паузу (500–3000 мс), повторы, число отсчёта и итоговый текст. `{user}` заменяется именем пользователя Telegram. Привяжите сценарий к кнопке и перезапустите бота. Бот отправит одно сообщение и будет редактировать его; Telegram может ограничивать частоту запросов. Одновременно допускается до пяти анимаций.

`.bc` экспортирует всего бота со сценариями и анимациями; импорт заменяет текущего бота после подтверждения. Кнопка «Экспорт анимации .bca» сохраняет отдельную анимацию, а «Импорт анимации .bca» добавляет её как новый сценарий. `.bca` и `.bc` — JSON-форматы этой версии, **не совместимые с Android**. Старые `.bc` с текстовыми ответами поддерживаются. Android `.py`, фото-анимации, случайный итог из набора и моноширинное оформление не перенесены. Импортированные файлы не выполняются как код.


## Команды и фразы

В сценарии выберите «Команда Telegram» или «Сообщение содержит фразу». Команды начинаются с `/` и содержат до 32 латинских букв, цифр или `_`; `/help@ИмяБота` также распознаётся. Сопоставление не зависит от регистра. Один сценарий может одновременно иметь условие и быть привязан к кнопке. При совпадении нескольких условий приоритет: команда, кнопка, затем первая подходящая фраза в порядке сценариев. Для `/start` без собственного ответа показывается клавиатура, если кнопки есть; свой `/start` также показывает клавиатуру. Перезапустите бота после изменений.

Условия сохраняются в `.bc`. Экспортируйте резервную копию перед обновлением; версии приложения до 0.3 не исполняют эти условия. Исполняется текст или анимация, скрипты и другие действия Android пока не перенесены.
