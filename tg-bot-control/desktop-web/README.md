# Локальный веб-редактор BotControl (первый этап)

Требуется Python 3.9 или новее. Windows: `py server.py`; Linux: `python3 server.py` (в этой папке). Откроется браузер по адресу http://127.0.0.1:8765/. Остановить сервер: Ctrl+C. Другой порт: `python3 server.py --port 8766`. Сервер слушает только локальный интерфейс и не выполняет импортированные файлы.

Создайте сценарии и привяжите их к кнопкам. Изменения хранятся в локальном хранилище конкретного браузера и могут исчезнуть при очистке его данных. Экспортируйте `.bc` для резервной копии и переноса. Импорт `.bc` заменяет текущего бота после подтверждения; файл представляет собой JSON версии 1. Токены в редакторе не используются.

Импорт ответов: текстовый файл UTF-8, каждый ответ начинается с номера и точки (или скобки), например:

```text
1. Первый ответ
2. Второй ответ
   продолжение второго ответа
```

Ответы добавляются как сценарии, существующие данные не заменяются. При необходимости можно изменить их названия и привязать к кнопкам.

## Запуск бота

Создайте хотя бы один непустой сценарий и кнопку с уникальным названием, привяжите её к сценарию. Вставьте токен от @BotFather и нажмите «Запустить бота». Откройте бота в Telegram и отправьте `/start`: появится клавиатура, кнопки будут отправлять привязанные ответы. Для работы нужны интернет и запущенный `server.py`; браузер можно закрыть. После редактирования остановите и заново запустите бота. Один токен нельзя одновременно использовать для polling на другом устройстве. Токен не сохраняется и не экспортируется; после перезапуска его нужно ввести заново.

**Ограничения:** реализованы только текстовые ответы и клавиатура с кнопками, не все функции Android. Формат `.bc` пока не совместим с Android-приложением; импорт и экспорт `.py` не реализованы. Данные редактора хранятся в браузере, а не в процессе бота. Это локальное приложение, а не публичный веб-сервис. Не предоставляйте доступ к нему другим пользователям. При завершении `server.py` бот останавливается.

## Windows: запуск и сборка

Готовая Windows-сборка создаётся заданием **BotControl Windows** в GitHub Actions. После успешного запуска скачайте артефакт `BotControl-Windows`, распакуйте архив и запустите `BotControl.exe`. Установка Python для этого не нужна. Программа открывает браузер и оставляет консольное окно открытым: пока окно работает, бот может отвечать. Закрытие окна останавливает бота. При повторном запуске введите токен заново. Не распространяйте непроверенные исполняемые файлы; эта сборка не подписана и Windows может предупредить об этом.

Для запуска из исходников с установленным Python 3.9+ можно дважды нажать `Start-BotControl.cmd`. При занятом порте 8765 закройте уже работающий экземпляр; не выбирайте произвольный порт как постоянный обходной путь: хранилище браузера привязано к адресу и порту. При использовании другого браузера или порта импортируйте резервную копию `.bc`.

Сборка на Windows вручную (Python 3.11, из этой папки):

```powershell
py -3.11 -m pip install pyinstaller==6.11.1
py -3.11 -m PyInstaller --noconfirm --clean --onefile --name BotControl --add-data "index.html;." --add-data "style.css;." --add-data "app.js;." server.py
```

Результат — `dist\BotControl.exe`. Это не установщик и не отдельный нативный интерфейс: управление происходит в браузере на локальном компьютере.
