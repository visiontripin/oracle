# Локальный веб-редактор BotControl (первый этап)

## Новое в сборке 0.6.0 (исправления по итогам тестирования)

- Остановка бота занимает до 5 секунд; добавлена кнопка **«Перезапустить»** (токен подставляется из памяти запущенного процесса).
- Сообщения больше не теряются, если ответ одному пользователю не удался: сбой пишется в журнал с chat ID, остальной пакет обрабатывается.
- Открываются адреса `http://localhost:8765/` и `http://127.0.0.1:8765/`; чужие адреса получают страницу с подсказкой.
- Ошибки различают причину: токен не принят Telegram / нет связи с интернетом / ошибка конкретного запроса.
- Фразы-триггеры срабатывают по целым словам («кот» не срабатывает на «скот»), фразы-смайлы — по-прежнему как подстрока.
- Напоминания: окно допуска 10 минут и повтор при сбое отправки; chat ID можно узнать командой боту `/chatid`.
- Импорт списков из Android `.py` отсеивает кадры анимаций (`ANIM_*`, `*_FRAMES`, `photo:`) и служебные списки, диалог показывает превью каждого списка.
- Журнал показывает имя найденного сценария; занятый порт — русская подсказка.

Требуется Python 3.9 или новее. Windows: `py server.py`; Linux: `python3 server.py` (в этой папке). Откроется браузер по адресу http://127.0.0.1:8765/. Остановить сервер: Ctrl+C. Другой порт: `python3 server.py --port 8766`. Сервер слушает только локальный интерфейс и не выполняет импортированные файлы.

Создайте сценарии и привяжите их к кнопкам. Изменения хранятся в локальном хранилище конкретного браузера и могут исчезнуть при очистке его данных. Экспортируйте `.bc` для резервной копии и переноса. Импорт `.bc` заменяет текущего бота после подтверждения; файл представляет собой JSON версии 1. Токены в редакторе не используются.

Импорт ответов: текстовый файл UTF-8, каждый ответ начинается с номера и точки (или скобки), например:

```text
1. Первый ответ
2. Второй ответ
   продолжение второго ответа
```

Ответы добавляются как сценарии, существующие данные не заменяются. При необходимости можно изменить их названия и привязать к кнопкам.

## Запуск бота

Создайте непустой сценарий и задайте ему команду или фразу, либо добавьте кнопку с уникальным названием и привяжите её к сценарию. Вставьте токен от @BotFather и нажмите «Запустить бота». Откройте бота в Telegram и отправьте `/start`: появится клавиатура, кнопки будут отправлять привязанные ответы. Для работы нужны интернет и запущенный `server.py`; браузер можно закрыть. После редактирования нажмите «Перезапустить» (или остановите и запустите бота заново). Один токен нельзя одновременно использовать для polling на другом устройстве. Токен не сохраняется и не экспортируется; после перезапуска программы его нужно ввести заново (кнопка «Перезапустить» работает, пока программа не закрыта).

**Ограничения:** реализованы текстовые ответы, текстовые анимации и клавиатура с кнопками, не все функции Android. Формат `.bc` пока не совместим с Android-приложением; полный импорт и экспорт `.py` не реализованы; частично извлекаются списки ответов. Данные редактора хранятся в браузере, а не в процессе бота. Это локальное приложение, а не публичный веб-сервис. Не предоставляйте доступ к нему другим пользователям. При завершении `server.py` бот останавливается.

## Windows: запуск и сборка

Готовая Windows-сборка создаётся заданием **BotControl Windows** в GitHub Actions. После успешного запуска скачайте артефакт `BotControl-Windows`, распакуйте архив и запустите `BotControl.exe`. Установка Python для этого не нужна. Программа открывает браузер и оставляет консольное окно открытым: пока окно работает, бот может отвечать. Закрытие окна останавливает бота. При повторном запуске введите токен заново. Не распространяйте непроверенные исполняемые файлы; эта сборка не подписана и Windows может предупредить об этом.

Для запуска из исходников с установленным Python 3.9+ можно дважды нажать `Start-BotControl.cmd`. При занятом порте 8765 закройте уже работающий экземпляр; не выбирайте произвольный порт как постоянный обходной путь: хранилище браузера привязано к адресу и порту. При использовании другого браузера или порта импортируйте резервную копию `.bc`.

Сборка на Windows вручную (Python 3.11, из этой папки):

```powershell
py -3.11 -m pip install pyinstaller==6.11.1
py -3.11 -m PyInstaller --noconfirm --clean --onefile --name BotControl --add-data "index.html;." --add-data "style.css;." --add-data "app.js;." --add-data "generated.js;." server.py
```

Результат — `dist\BotControl.exe`. Это не установщик и не отдельный нативный интерфейс: управление происходит в браузере на локальном компьютере.

## Android / Termux

Для экспериментального запуска в Termux и управления из браузера в доверенной домашней Wi‑Fi сети см. [подробную инструкцию](TERMUX.md). Публичный доступ не реализован; LAN-режим не имеет авторизации и HTTPS.

Предварительная сборка для Windows публикуется как отдельный prerelease; кроме тестов приложения CI запускает собранный `.exe` и проверяет выдачу страницы и статуса. Интеграция с реальным Telegram в CI не проверяется.


## Анимации

Создайте сценарий, выберите действие «Анимация» и один из 10 текстовых шаблонов Android: спиннер, прогресс, точки, отсчёт, печатная машинка, матрица, слоты, луна, часы или сердце. Также можно создать свои кадры, разделяя их строкой `---`. Укажите подпись, паузу (500–3000 мс), повторы, число отсчёта и итоговый текст. `{user}` заменяется именем пользователя Telegram. Привяжите сценарий к кнопке и перезапустите бота. Бот отправит одно сообщение и будет редактировать его; Telegram может ограничивать частоту запросов. Одновременно допускается до пяти анимаций.

`.bc` экспортирует всего бота со сценариями и анимациями; импорт заменяет текущего бота после подтверждения. Кнопка «Экспорт анимации .bca» сохраняет отдельную анимацию, а «Импорт анимации .bca» добавляет её как новый сценарий. `.bca` и `.bc` — JSON-форматы этой версии, **не совместимые с Android**. Старые `.bc` с текстовыми ответами поддерживаются. Полный импорт Android `.py`, фото-анимации, случайный итог анимации из набора и моноширинное оформление не перенесены. Импортированные файлы не выполняются как код.


## Команды и фразы

В сценарии выберите «Команда Telegram» или «Сообщение содержит фразу». Команды начинаются с `/` и содержат до 32 латинских букв, цифр или `_`; `/help@ИмяБота` также распознаётся. Сопоставление не зависит от регистра. Фраза ищется по целым словам: «кот» не сработает на «скот», «привет» — на «приветствую»; фразы из смайлов и знаков ищутся как подстрока. Один сценарий может одновременно иметь условие и быть привязан к кнопке. При совпадении нескольких условий приоритет: команда, кнопка, затем первая подходящая фраза в порядке сценариев. Для `/start` без собственного ответа показывается клавиатура, если кнопки есть; свой `/start` также показывает клавиатуру. Перезапустите бота после изменений.

Условия сохраняются в `.bc`. Экспортируйте резервную копию перед обновлением; версии приложения до 0.3 не исполняют эти условия. Исполняется текст, случайный ответ или анимация, скрипты и другие действия Android пока не перенесены.


## Новые функции предварительной версии

- **Набор ответов:** в сценарии выберите «Случайный ответ из набора», введите каждый вариант на отдельной строке. Это набор внутри сценария, не общая библиотека Android. Сохраняется в `.bc`.
- **Кнопки под сообщением:** в сценарии можно добавить до трёх ссылок HTTP/HTTPS. Реакции на нажатия, callback-кнопки, редактирование сообщения и включение напоминаний кнопкой пока не поддерживаются.
- **Напоминания:** укажите время компьютера, дни, числовой chat ID и сценарий. Чтобы узнать chat ID, отправьте боту команду `/chatid` (или запустите бота, напишите ему и откройте журнал работы). Бот должен иметь право писать в чат. Напоминания выполняются только пока программа запущена и компьютер не спит. Пропущенное время отрабатывает в течение 10 минут; при сбое отправка повторяется в этом окне (в журнале видно, что событие отработает повторно). После закрытия программы неотправленные события не воспроизводятся. Это не полноценный планировщик Android.
- **Импорт из Android `.py`:** кнопка «Наборы из Android .py» извлекает только буквальные верхнеуровневые списки или кортежи строк с именами в верхнем регистре. Код не выполняется. Команды, условия, кнопки, расписание и остальные настройки не импортируются. Проверьте извлечённые списки перед использованием: не все из них являются ответами.
- **Проверка и журнал:** имитация использует те же правила выбора сценария, но не отправляет сообщения в Telegram; для анимации показывает первый кадр. Журнал хранится в памяти процесса, содержит chat ID, но не содержит текстов сообщений и токенов; после закрытия очищается.

Сохраните резервную копию `.bc` перед обновлением. Новые типы действий, ссылки и напоминания в старых версиях не исполняются. Для Windows версия не подписана и не тестировалась с живым Telegram. Не используйте экспериментальный планировщик для критически важных уведомлений.


## Создание бота с языковой моделью

В разделе «Создать бота по описанию» скопируйте готовый промпт, замените описание в конце и отправьте его выбранной языковой модели. **Не отправляйте токен, пароли или личные данные модели.** Скопируйте её ответ в поле и нажмите «Проверить и импортировать», либо сохраните ответ в `.txt`/`.bc` и выберите файл там же. Допускается один JSON-объект, в том числе в блоке ```json; Python и произвольный код не выполняются.

Импорт проверяет структуру, привязки и параметры запуска, показывает число сценариев/кнопок/напоминаний и запрашивает подтверждение замены текущего бота. Ошибочный или отменённый импорт не заменяет текущую конфигурацию. Перед импортом сохраните резервную копию `.bc`. Проверьте импортированный текст, адреса ссылок и настройки, используйте проверку сценария и перезапустите работающего бота. Приложение не подключается к модели и не передаёт ей данные автоматически. Формат описывает только поддерживаемые возможности Windows-версии и не совместим с Android.
