# Первый этап: BotControl в Termux и управление по Wi‑Fi

Это экспериментальный локальный сервер без авторизации и шифрования. Используйте **только в доверенной домашней сети** и не открывайте порт наружу, не включайте туннель или публичный доступ. Любой участник сети, имеющий адрес, может запустить и остановить бота, а токен передаётся по сети открытым текстом. Веб-редактор сохраняет конфигурацию в браузере компьютера, а не в Termux; используйте экспорт `.bc` как резервную копию. Это не полная версия Android: сейчас поддерживаются только одна работающая конфигурация, текстовые сценарии и кнопки. Импорт `.py`, анимации, расписания, объявления и другие функции ещё не перенесены.

## Установка

1. Установите актуальный Termux из [F-Droid](https://f-droid.org/packages/com.termux/) или официальных релизов [Termux на GitHub](https://github.com/termux/termux-app/releases). Не смешивайте сборки Termux и его дополнений из разных источников. Старые сборки из Google Play могут не подходить.
2. Откройте Termux и выполните:

   ```sh
   pkg update && pkg upgrade
   pkg install python git
   git clone https://github.com/visiontripin/oracle.git
   cd oracle/tg-bot-control/desktop-web
   ```

   До включения изменений в `main` используйте вместо команды клонирования: `git clone --branch arena/923bbc26-oracle https://github.com/visiontripin/oracle.git`. Для обновления существующей копии: `cd ~/oracle && git pull --ff-only`.
3. Узнайте IPv4-адрес телефона в настройках текущей сети Wi‑Fi, например `192.168.1.25`. Используйте **свой** адрес; он может измениться при переподключении. Подключите компьютер к той же сети.
4. В папке `~/oracle/tg-bot-control/desktop-web` запустите, подставив адрес телефона:

   ```sh
   python server.py --host 192.168.1.25 --no-browser
   ```

5. На компьютере откройте в браузере адрес, напечатанный Termux, например `http://192.168.1.25:8765/`. Создайте сценарий и кнопку, привяжите сценарий к кнопке. Вставьте токен тестового бота от @BotFather и нажмите «Запустить бота». В Telegram отправьте этому боту `/start` и нажмите кнопку. Не публикуйте и не присылайте токен другим людям.
6. Для остановки бота нажмите «Остановить». Для остановки сервера в Termux нажмите Ctrl+C; при этом бот также остановится. Закрывать вкладку браузера можно, пока Termux продолжает работать.

По умолчанию `python server.py` слушает только `127.0.0.1`, то есть доступен лишь на самом телефоне. Параметр `--host` принимает только loopback или конкретный частный IPv4-адрес, назначенный телефону; `0.0.0.0` и публичные адреса запрещены. Если адрес изменился, остановите сервер и запустите с новым адресом. Данные браузера привязаны к адресу и порту: при их изменении импортируйте заранее экспортированный `.bc`.

## Если не подключается

- Убедитесь, что оба устройства подключены к одной доверенной Wi‑Fi сети, адрес введён точно, а сервер остаётся запущенным. Гостевая сеть или изоляция клиентов роутера могут блокировать соединение.
- `Cannot start server`: адрес не назначен телефону или порт занят. Остановите прежний экземпляр либо укажите `--port 8766` и откройте соответствующий адрес (у другого порта будет отдельное хранилище браузера).
- Если бот не отвечает, проверьте интернет, токен и то, что тот же токен не используется одновременно другим приложением. Состояние показывается на странице.
- Android может приостанавливать или завершать Termux в фоне. Отключите ограничения батареи для Termux в настройках Android и, если необходимо, выполните `termux-wake-lock`. Это не гарантирует непрерывную работу. После перезагрузки телефона сервер и бот нужно запустить заново; автоматический запуск пока не реализован. Токен хранится только в памяти процесса и потребуется снова.

Публичный доступ и подключение через мобильную сеть на этом этапе **не реализованы**. Не используйте эту сборку для конфиденциальных данных в недоверенной сети.
