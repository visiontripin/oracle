Как это работает

  1. Создайте сценарий с ответом.
  2. Выберите команду или фразу; при желании привяжите кнопку.
  3. Экспортируйте бота в файл .bc.

Из Android .py пока можно извлечь только буквальные списки ответов; другие настройки не переносятся.
